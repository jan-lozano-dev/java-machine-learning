# Java Machine Learning

Implementations of machine learning algorithms from scratch in Java, developed to understand their mathematical foundations and practical implementation.

## Algorithms

| Algorithm | Type | Status |
|---|---|---|
| Linear Regression | Supervised Learning · Regression | Implemented |

More algorithms will be added as the project progresses.

## Goals

- Implement core machine learning algorithms from first principles.
- Understand the mathematics behind each algorithm.
- Explore optimization methods and model evaluation.
- Progress toward more advanced topics, including neural networks and reinforcement learning.
